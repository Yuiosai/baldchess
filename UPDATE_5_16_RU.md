# BaldChess 5.16 — полная версия для GitHub / Render

## Что исправлено

- **Оригинальные фигуры и все скины сохранены** — от версии 5.13.
- **Звуки**: единый негромкий звук шахматных фигур на деревянной доске,
  синтезируемый локально в браузере (не файлы с Chess.com или Lichess).
  Для взятия — слегка иной щелчок; стиль скина на звук не влияет.
- **Громкость**: в существующем блоке «Отображение» появился компактный
  переключатель «Звуки ходов». Положение сохраняется в браузере.
- **Ориентация**: каждый участник смотрит на доску со своей стороны:
  красные снизу, жёлтые снизу для своего клиента, синие и зелёные — тоже
  снизу для соответствующих клиентов в игре на четверых. Фигуры остаются
  вертикальными, независимо от поворота доски.
- **Рокировка**: клик или перетаскивание короля на его конечную клетку
  (c/g по собственному ряду), сохранилась возможность рокировки в Chess960,
  в котором король уже стоит на конечной клетке.
- **Премув**: подсвечивается только целевая клетка; нет всплывающей надписи
  об успешном сохранении и отдельной панели снизу. ПКМ на доске отменяет
  выбор и премув. Неверный премув при смене хода исчезает без всплывашки.
- **Отмена перетаскивания**: ПКМ и Escape удаляют временную копию фигуры;
  задержавшийся ответ сервера больше не возвращает отменённое выделение.
- **Небольшая анимация ходов** для своего хода и ответов других игроков;
  системное предпочтение уменьшенной анимации учитывается.

## Для публичного BaldChess

- В `index.html` добавлены title, описание, canonical, OpenGraph и Twitter Card.
- В корне лежат `robots.txt` и `sitemap.xml`.
- `server.py` умеет отдавать `robots.txt` и `sitemap.xml`.
- Все ссылки ориентированы на `https://baldchess.com/`.
- `render.yaml` оставляет исходный `rootDir: BaldChess` и стандартный хостинг Render.

## Как обновить GitHub

1. Распакуй ZIP. Внутри лежит папка `BaldChess`.
2. На GitHub открой корень репозитория `Yuiosai/baldchess`.
3. Заменяй содержимое **существующей** `BaldChess`, сохрани структуру,
   например `BaldChess/js/app.js`, `BaldChess/engine.py`, `BaldChess/server.py`.
   Не создавай второй вложенный каталог `BaldChess/BaldChess`.
4. Сделай Commit changes и дождись Live в Render.
5. Открой сайт и нажми Ctrl + Shift + R (жёсткая перезагрузка).
6. Проверь `https://baldchess.com/robots.txt` и
   `https://baldchess.com/sitemap.xml`.
7. В Google Search Console → Файлы Sitemap введи `sitemap.xml`.

## Проверка

```sh
python -m unittest discover -s tests -v
node tests/test_client_game_516.js
```

Для Render Free: SQLite-файл находится на временном диске.
При перезапуске/новом деплое комнаты и их данные могут потеряться.
Для долговременных партий нужна отдельная постоянная база данных или диск.
Запрос индексации не гарантирует появление сайта в Google.
