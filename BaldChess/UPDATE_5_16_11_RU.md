# BaldChess 5.16.11 — премувы, пешки и единый сайт

1. **Премув:** нажатие на любую свою активную фигуру отменяет текущий премув, при этом сразу выбирает нажатую фигуру для нового хода. Отмена ПКМ и кнопкой сохранена. Обычный ход и чужие фигуры не меняют логику отмены.
2. **Пешки:** переработаны симметричные контуры двух пешек, у чёрной на шейке/воротнике нет постороннего белого пятна. SVG автоматически совпадают с `js/pieces.js`.
3. **Поисковые страницы:** две ненужные самостоятельные страницы-инструкции убраны, старые URL дают 301 на главный сайт. Sitemap теперь содержит только одну страницу; главная получила русские поисковые формулировки.
4. **Не трогали:** управление комнатами, мультиигровую механику, мобильные таймеры, скролл/центрирование доски, управление звуками, цветовые скины и прежние улучшения.

Обнови все файлы в репозитории из вложенной папки `BaldChess/`, затем Render должен развернуть обновление из GitHub. Обнови браузер Ctrl+F5. Файлы в ZIP не публикуются автоматически.
