BaldChess classic figures — version 5.16.10.
These are standalone SVG reference files generated from the same original path geometry as js/pieces.js.
The website renders the figures inline via js/pieces.js; browsers do not need to download or install any fonts.
White files (w*) use a white fill with dark outlines; black files (b*) use a black fill with light inner detailing.
Blue, green and other board-theme colors are rendered dynamically using the selected palette.
No bitmap cutouts or external images are used.
