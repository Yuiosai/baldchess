# BaldChess 5.16 — multiplayer chess for 2 or 4 players

Игра для друзей с комнатами по коду. **Без регистрации и без сторонних Python-библиотек.** Проект включает HTML, CSS, JavaScript и сервер на Python 3.9+.

## Быстрый запуск (Windows)

1. Распакуйте архив **полностью**.
2. Откройте папку `BaldChess` и дважды нажмите `START_WINDOWS.bat`.
3. Если браузер не открылся автоматически, перейдите на `http://localhost:8000`.
4. Выберите **1 VS 1** или **4 PLAYERS**. Ниже можно сменить язык **English (по умолчанию) / Русский**.
5. Задайте правила, создайте комнату и отправьте друзьям **шестисимвольный код** или ссылку-приглашение. Друзья выбирают **Join with room code / Войти по коду**.
6. Не закрывайте консольное окно — это сервер игры.

Если `START_WINDOWS.bat` не работает, откройте терминал в папке проекта и выполните `python server.py` (или `py -3 server.py`). Для другого порта: `python server.py --port 8080`. Не запускайте `index.html` напрямую: браузеру нужен игровой сервер.

## Как играть с друзьями

- **Дома / в одной локальной сети:** сервер запускается на одном компьютере. Друзьям требуется адрес `http://IP_компьютера:8000` (узнать IP через `ipconfig`). При запросе Windows разрешите сетевой доступ Python.
- **В разных сетях:** официальный адрес проекта — `https://baldchess.com/` (после успешной публикации в Render). Для самостоятельного хостинга нужен публичный сервер; `localhost` недоступен друзьям из другого города.
- Можно играть **1 на 1** (обычная доска 8×8, красные против жёлтых) или **вчетвером** (доска 14×14 с вырезанными углами, четыре цвета).
- Порядок ходов при четверых: красные → синие → жёлтые → зелёные.
- Играйте мышкой: **перетащите** фигуру на клетку или **нажмите** на фигуру, затем на клетку. При выборе допустимые ходы подсвечиваются.

## Комнаты, переподключение и замена игрока

- **Никаких аккаунтов, паролей и регистрации**. Каждый участник получает секретный токен места, который сохраняется в `localStorage` **в его браузере**.
- После обрыва связи или перезапуска страницы **откройте ту же комнату тем же браузером** — ваше место и цвет вернутся автоматически. Смена браузера, очистка данных сайта или потеря токена лишают этого способа восстановления.
- Игрок считается отключившимся примерно через **12 секунд** без запросов к серверу. Хост (первый, красный игрок) увидит кнопку **Take control / Взять управление** рядом с отключённым участником. Можно взять управление **несколькими** отключёнными цветами одновременно, включая двоих или троих игроков.
- Когда игрок снова подключается со своим токеном, управление хоста **автоматически прекращается**. Это сделано, чтобы не было одновременных ходов двумя людьми за один цвет.
- Ход окончательно проверяет сервер. Состояние комнат хранится в SQLite (`data/rooms.sqlite3` по умолчанию). При первом запуске старые комнаты из `data/rooms.json` автоматически переносятся в SQLite.

## Правила и настройки

- **Chess960 / Фишер:** одна случайно созданная перестановка фигур первого ряда применяется **одинаково ко всем участникам** (относительно их собственной стороны). Слоны стоят на разноцветных клетках, король между ладьями. Рокировка: выберите короля и конечную клетку короля (c/g по своему ряду); если в Chess960 король уже стоит там, допускается нажатие на ладью.
- **Custom board / Своя расстановка:** расставьте и удалите фигуры с помощью редактора. В каждой команде цвета должен быть **один король**. В пользовательской расстановке рокировка отключена.
- **Pawn promotion / Превращение пешек:** ферзь, ладья, слон или конь на выбор.
- **Пешки** ходят в фиксированном направлении, как принято для стороны доски. Дополнительного переключателя направления нет.
- **Часы:** без времени или 1/3/5/10/15/30/60 мин; можно задать каждому игроку своё время, выбрать прибавку секунд за ход.
- **Премувы:** один ожидающий ход подсвечен только на целевой клетке; сработает автоматически в свой ход, если допустим. ПКМ по доске отменяет премув и выделение. Можно выключить в настройках комнаты; премув хранится только в текущей вкладке.
- **Команды:** доступны **только в игре на четверых**. Настройка 2×2, 3×1, 2+1+1 и любые сочетания через назначения A–D. Союзники не берут фигуры друг друга.
- **Customize Board / Кастомизация доски:** две вкладки — 6 цветовых палитр и 6 художественных наборов (Dragon Realm, Iron Citadel, Galactic, Arcane, Celestial, Abyss). Любой выбор меняет цвета доски, форму и окраску фигур одним пакетом. Настройка сохраняется за местом игрока и видна другим. Отдельный локальный переключатель **Show other players’ skins** либо показывает стилизованные зоны и фигуры всех игроков, либо отображает всю доску в вашей теме.

## Язык интерфейса

На стартовом экране выбирайте **English** или **Русский**; язык также переключается в верхнем меню во время игры. По умолчанию — английский. Предпочтение сохраняется в браузере. Системные имена игроков и вводимые самими игроками названия не переводятся.

## Ограничения

Это любительский вариант шахмат для 2 и 4 игроков, не точная копия Chess.com. Нет рейтинга и профилей, повтора партий, правил 50 ходов и повторения позиции, согласованных ничьих и анимаций. Правила многопользовательского шаха, пата и выбытия — авторская упрощённая версия. Взятие на проходе реализовано в базовом варианте и может отличаться от правил конкретных сайтов для четырёх. При выбывании фигуры остаются на поле препятствиями, но не могут ходить и не создают шах.

**Не выставляйте домашний сервер напрямую в публичный интернет.** На хостинге включите HTTPS и обеспечьте постоянное хранилище для SQLite. Лимиты запросов — базовая защита, не замена инфраструктурному rate limiting и мониторингу.

## Обновление 5.11 — подготовка к публикации

- Только создатель комнаты (красное место) может **менять правила лобби**, пока матч не начался. После подключения других участников нельзя менять число игроков/формат доски 1v1 ↔ 4-player; цвета доски и художественные скины каждый выбирает **самостоятельно** в любой момент.
- Классические фигуры сделаны немного крупнее; художественные фигуры тоже занимают чуть больше площади клетки. Размер поля и адаптивная вёрстка 5.10 не менялись.
- Сервер ограничивает запросы по **IP клиента**: создание — 10/мин, подключения — 30/мин, игровые действия — 120/мин и получение состояния — 240/мин. Не более 300 комнат в памяти одновременно. Неактивные комнаты удаляются через 2 дня ожидания, 7 дней после завершения или 30 дней игры без сохранённых действий.
- Состояния комнат сохраняются в **SQLite**: по умолчанию `data/rooms.sqlite3`; можно задать `BALDCHESS_DB=/постоянный/путь/rooms.sqlite3`. Если остался старый файл `data/rooms.json`, сервер один раз импортирует сохранения. База содержит секретные токены участников — не публикуйте её и не отправляйте посторонним.
- Токены мест игроков передаются в HTTP-заголовке `X-BaldChess-Token`; URL содержит только публичный код комнаты. Нужен HTTPS в интернете.

### Размещение в интернете

Запустите **один процесс** командой `python server.py --no-browser` (на хостинге автоматически используется переменная `PORT`). Для продакшена разместите Python-приложение за HTTPS reverse proxy, настройте постоянный диск или другую надёжную базу данных. **SQLite не переживёт перезапуск бесплатного временного контейнера без постоянного тома**, даже при наличии файла внутри приложения. Не включайте несколько независимых серверных процессов: память комнат синхронизируется только внутри одного Python-процесса. Если трафик идёт через общий прокси, лимиты по IP следует также настраивать на доверенном внешнем прокси, поскольку приложение может видеть одинаковый IP для разных посетителей.

Файл `.gitignore` исключает базу, секреты и кэш, чтобы их случайно не отправить на GitHub. Отдельные пользовательские профили и пароли не реализованы: восстановление места происходит по локальному токену браузера.

## Branding / Google Translate

BaldChess is a proper brand name, not a term to translate. The site uses a built-in English/Russian language selector. The page contains `meta name="google" content="notranslate"` plus `translate="no"` and `class="notranslate"` on visible brand labels to avoid Chrome/Google translating it to literal words. The browser page title is also protected.

For this branding-only update on GitHub, you only need to replace `BaldChess/index.html`; Render can auto-deploy the commit.
